# Phase 1: Git Sync — isomorphic-git

> **Status:** em andamento
> **Data:** 2026-06-07

## Objetivo

Implementar sync Git puro em JS (isomorphic-git) que funcione no desktop E mobile, sem depender do binário `git` do sistema nem do plugin Git oficial do Obsidian.

## Arquitetura

```
Obsidian User
  → Comando "Sincronizar" / Ribbon Icon / Auto-sync
    → GitSync.sync()
      → VaultFS (bridge isomorphic-git ↔ Obsidian Vault API)
      → isomorphic-git: pull → add → commit → push
      → StatusBar update
```

### Componentes

| Módulo | Arquivo | Descrição |
|--------|---------|-----------|
| **VaultFS** | `src/git/vault-fs.ts` | Bridge entre `FsClient` do isomorphic-git e `Vault` do Obsidian |
| **GitSync** | `src/git/sync.ts` | Orquestrador: status, pull, add+commit, push |
| **StatusBar** | Em `main.ts` | Widget mostrando branch + últimos commits |

## Fluxo de sync

```
sync():
  1. git.statusMatrix() → detecta mudanças locais
  2. git.pull(fastForwardOnly: true) → baixa remoto (só fast-forward, sem merge)
  3. Se mudanças locais:
     a. git.add() → stage tudo
     b. git.commit() → "vault: auto-sync YYYY-MM-DD HH:MM"
  4. git.push() → envia
  5. Retorna { pulled: N, pushed: N }
```

## VaultFS — Bridge

isomorphic-git usa `PromiseFsClient`:
```ts
{ promises: { readFile, writeFile, unlink, readdir, mkdir, rmdir, stat, lstat } }
```

Traduzimos cada chamada para o Obsidian `Vault` API:
- `readFile(path)` → `adapter.readBinary(path)` → `new Uint8Array(arrayBuffer)`
- `writeFile(path, data)` → `adapter.writeBinary(path, data)`
- `unlink(path)` → `adapter.remove(path)`
- `readdir(path)` → `adapter.list(path)` → `files.concat(folders)`
- `mkdir(path)` → `adapter.mkdir(path)`
- `rmdir(path)` → `adapter.rmdir(path)`
- `stat(path)` → `adapter.stat(path)` → `{type, mtime, size}`

## HTTP Auth

Token do GitHub via header:
```ts
headers: { Authorization: `Bearer ${token}` }
```

Ou via `onAuth` callback que popula `{ username: token, password: 'x-oauth-basic' }`.

## Riscos

| Risco | Mitigação |
|-------|-----------|
| `.git/` bloqueado pelo Obsidian no mobile | Testar acesso a `.git/` via adapter; fallback: fs do Node no desktop |
| Conflito de merge | Usar `fastForwardOnly: true` no pull; se falhar, logar e pedir resolução manual |
| Token expirado | Capturar erro HTTP 401 e notificar usuário |
| Arquivos binários grandes | Ignorar via `.gitignore`; sync só de markdown |
